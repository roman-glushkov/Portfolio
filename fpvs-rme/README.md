# ФПВС РМЭ — сайт федерации пляжных видов спорта

Статический сайт на HTML, CSS и JavaScript без сборщика. Публичная страница и админка — две самостоятельные точки входа: `index.html` и `admin.html`.

## Структура

- `partials/` — HTML-фрагменты главной страницы и админки.
- `css/` — стили сайта разделены по секциям; адаптивные правила вынесены в отдельные файлы. `css/admin-*.css` используется только админкой.
- `js/core/` — общие небольшие утилиты и загрузчик фрагментов.
- `js/ui/`, `js/data/`, `js/forms/`, `js/modals/` — поведение публичного сайта по назначению.
- `js/admin/` — отдельная логика входа, статистики, заявок и модального окна админки.
- `data/` — JSON-данные новостей, турниров, календаря, альбомов и статистики.
- `images/` — изображения сайта и фотографии альбомов.

Кодовые и текстовые файлы проекта разделены так, чтобы оставаться в пределах 200 строк на файл. Старые `style.css`, `script.js` и `views.js` оставлены как короткие совместимые точки входа; основная страница напрямую подключает модули.

## Запуск

Открой папку проекта через VS Code и запусти `index.html` с помощью Live Server или раздай папку любым статическим HTTP-сервером. Не открывай файл через `file://`: сайт использует `fetch()` для JSON и HTML-фрагментов, а браузерные ES-модули требуют HTTP(S).

Админка открывается отдельно по адресу `admin.html`. Доступ к панели ограничивается проверкой активной Appwrite-сессии и членства в команде с ID `admins`.

## Appwrite

1. Открой [Appwrite Console](https://cloud.appwrite.io/console) и выбери проект.
2. В настройках проекта добавь Web-платформу для localhost и домена опубликованного сайта.
3. Проверь значения `endpoint`, `projectId`, `databaseId` и `collectionId` в `appwrite-config.js`.
4. Для заявок должна существовать коллекция `leads` в указанной базе. Публичной форме нужно разрешение на создание заявок, но не публичное чтение, обновление или удаление.
5. Для входа в админку создай команду с ID `admins` и добавь в неё аккаунты администраторов. Панель использует Appwrite Account, Teams и Databases SDK.
6. Для отображения статистики должны существовать используемые исходным проектом данные посещений `page_views`. Публичный счётчик использует TablesDB API, а панель чтения статистики сохраняет исходный вызов Appwrite Databases.

Не добавляй API key или другие секреты в браузерный код. Для публичного запуска приём заявок лучше перенести в Appwrite Function с серверной проверкой и защитой от спама.
