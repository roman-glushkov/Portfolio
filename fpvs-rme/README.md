# ФПВС РМЭ — сайт федерации пляжных видов спорта

Статический сайт на HTML, CSS и JavaScript. Данные новостей, календаря, турниров, альбомов и статистики лежат в JSON.

## Реализовано

- большой пляжный hero;
- лента новостей и постов;
- турниры и календарь;
- интерактивная демонстрационная сетка волейбола/футбола;
- фотолента, альбомы и лайтбокс;
- блок Сергея Канашина и команды;
- контакты и адаптивная форма обратной связи;
- отправка формы заявок в Appwrite DocumentsDB после настройки `appwrite-config.js`.

## Запуск

Открой папку проекта в VS Code и запусти `index.html` через Live Server. Не открывай страницу через `file://`, поскольку сайту нужно загружать локальные JSON-файлы и обращаться к Appwrite.

## Подключение Appwrite

1. Создай или выбери проект в [Appwrite Console](https://cloud.appwrite.io/console).
2. Добавь Web-платформу для локального адреса и затем для домена опубликованного сайта.
3. В DocumentsDB создай базу и коллекцию `leads`.
4. В разрешениях коллекции выставь `Create → Any`. Не разрешай `Read`, `Update` или `Delete` роли `Any`.
5. Заполни `endpoint`, `projectId`, `databaseId` и `collectionId` в `appwrite-config.js`.
6. Отправь тестовую заявку и проверь документ в Appwrite Console.

Подробные шаги, разрешения и устранение ошибок — в [APPWRITE_SETUP.md](APPWRITE_SETUP.md).

## Важное замечание о безопасности

Для публичной формы разрешена только запись новых заявок. Не добавляй API key или другие секреты в HTML, CSS, JavaScript или JSON. Перед масштабным публичным запуском рекомендуется вынести приём заявок в Appwrite Function для серверной проверки и ограничения спама.
